# Ecommerce Sales Dashboard

This repository contains a Power BI dashboard for analyzing ecommerce sales performance.

## File

- `Purushottam Ecommerce Sales Dashboard.pbix` - Power BI dashboard file

## About

The dashboard is designed to help review ecommerce sales data through visual reports and interactive insights. It can be used to explore sales trends, business performance, and key ecommerce metrics.

## How to Open

1. Download or clone this repository.
2. Open `Purushottam Ecommerce Sales Dashboard.pbix` in Microsoft Power BI Desktop.
3. Refresh or update the data source if required.

## Requirements

- Microsoft Power BI Desktop
